3 Program Sections & Agenda

This one list controls both the printed agenda page and which content sections appear elsewhere in the booklet. Required rows are locked in (traditional/BSA CoH items); you can edit their presenter text and reorder them, but not remove them. Optional rows are off by default — check Include to add them to the agenda and print a matching page. Custom rows are agenda-only (no content page) — use them for memorials, guest speakers, songs, or anything else.

Use the source PDF for archival or if you need to re-impose with another tool. Use the booklet PDF for printing: duplex long-edge (the printer default), US Letter, no scaling, then fold each sheet in half along the vertical center.
